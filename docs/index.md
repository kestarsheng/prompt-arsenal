## 🚀 快速上手

1. **浏览模板** → 在左侧导航栏找到你需要的场景
2. **复制提示词** → 点击右上角「📄 源码」查看并复制原始 Markdown
3. **粘贴给 AI** → 在对话中粘贴提示词，替换 `[变量]` 即可使用
4. **自由扩展** → Fork 仓库，按 `templates/prompt-template.md` 模板添加你自己的提示词
