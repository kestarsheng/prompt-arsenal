# 模拟技术面试

## 适用场景
准备面试时，想模拟真实面试问答。

## 输入变量
- `{{position}}`: 应聘职位（如 Java 高级开发工程师）
- `{{experience}}`: 工作年限
- `{{tech_stack}}`: 主要技术栈
- `{{focus_areas}}`: 重点考察方向

## 提示词模板
请模拟一次 {{position}} 的技术面试：

**面试信息：**
- 职位：{{position}}
- 工作年限：{{experience}}
- 技术栈：{{tech_stack}}
- 重点方向：{{focus_areas}}

**面试流程：**
1. 自我介绍环节（你扮演面试官，我先自我介绍，然后你点评）
2. 技术问答（10 个问题，由浅入深）
3. 系统设计题（1 个场景题）
4. 面试官反问环节（让我提问）
5. 面试反馈（优点、不足、建议）

**问答要求：**
- 问完一个问题后，等我回答，再给出点评
- 追问至少 2 次（考察深度）
- 如果回答有偏差，给出提示引导

**输出格式：**
按步骤分轮次进行，每轮给出问题和点评。

## 使用示例
**输入：**
- 职位: Java 高级开发工程师
- 技术栈: Spring Boot, MySQL, Redis, Kafka
- 重点方向: 高并发、事务、分布式

**AI输出：**
（开始模拟面试）
