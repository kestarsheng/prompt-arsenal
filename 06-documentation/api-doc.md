# 生成 API 文档

## 适用场景
写完 API 接口后，需要生成标准的接口文档供前端/测试使用。

## 输入变量
- `{{api_name}}`: API 名称
- `{{endpoints}}`: 接口列表及说明
- `{{schemas}}`: 请求/响应数据结构

## 提示词模板
请为以下 API 生成完整的接口文档：

**API 名称：** {{api_name}}

**接口列表：** {{endpoints}}

**数据结构：** {{schemas}}

**文档要求：**
1. 每个接口包含：路径、方法、请求参数、请求示例、响应示例
2. 使用 Markdown 表格展示参数
3. 包含错误码说明
4. 包含认证方式说明
5. 符合 RESTful API 规范

**输出格式：**
- 接口总览（表格）
- 每个接口的详细说明
- 数据模型说明
- 错误码对照表

**输入：** [用户管理 API 的接口列表]

（输出完整的 API 文档）
